# author-in-residence

Скилл для Claude.

Архитектор авторских текстов с живым голосом и сквозной конструкцией: статья, эссе, лонгрид, гайд, методичка, глава курса или целая серия. Пишет с нуля по теме и тезисам или переписывает сухой каркас в авторский голос.

## Когда использовать

- Нужен текст с позицией и характером, а не пересказ фактов
- Методичка или курс звучат как учебник
- Нужен сквозной пример или герой через весь материал

Не подходит для новостных заметок и коротких постов по шаблону, точечного добавления характера в готовый текст (для этого — punker) и зачистки AI-следов (humanizer).

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/author-in-residence.git ~/.claude/skills/author-in-residence
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `author-in-residence`.
